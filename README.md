# 🍋 레모나 도우미 (Lemona Companion)

**레모나 프리셋 전용** SillyTavern 확장입니다. 레모나의 구조(`</realism>`, `<thinkingProcess>`, 택1 토글, 「🚫 금지단어」)를 알아보고 그 안에 맞춰 끼워 넣습니다. 다른 프리셋에서는 일반 모드로 돌아갑니다.

## 지원 프리셋

| 버전 | 상태 |
|---|---|
| **레모나 v6.9.1** | **기준 버전.** 이 버전에 맞춰 만들고 확인했습니다 |
| 레모나 v7.2.1 | 함께 확인했습니다. 금지단어 목록과 끼워 넣는 지점이 v6.9.1과 같아서 그대로 동작합니다 |

두 버전을 오가며 써도 됩니다. 확장은 보낼 때마다 지금 켜진 프리셋을 읽습니다.

## 기능

| 기능 | 하는 일 | API 사용 |
|---|---|---|
| 🧠 캐릭터 해석 | **단일·다인봇·시뮬봇·RPG봇** 카드를 알아보고, 카드와 **로어북**을 같이 분석해 **겉과 속**(보여주는 모습·진짜 욕구·두려움·착각), **충돌하는 가치 쌍**, **사람에 따라**(특정 인물 앞에서 달라지는 모습)를 만들고, 「👤 현실적·캐해·로맨스」 바로 뒤에 넣음. 「🔍 추론」 체크리스트에 캐해 확인 줄도 추가 | 분석할 때 1번 |
| 🎛️ 토글 도우미 | 택1 그룹을 드롭다운으로 바꾸기, 구성 점검(택1 중복, 끄지마요 항목, 메신저+상태창 충돌, Argon/Carbon 설정 등), **캐릭터별 토글 세트** 저장·자동 적용(프리셋을 다시 불러와도 다시 적용), **모델 따라 🔷 Argon / 🔶 Carbon 자동 전환**, 분석 결과로 **토글 추천** (1차/2차봇, 혐성/젠틀, 로코, 앵스트, 분위기…) | 없음 (추천은 분석에 포함) |
| 🚫 금지어 검수 | 지금 프리셋의 「🚫 금지단어」를 그대로 읽어 답변마다 검사 → 본문 형광펜 + 배지. 파생형(서늘한→서늘하게), 제한어 1회·연속 금지, 교정 대비 구조(`A가 아니라 B` · `not A but B` · `He did not A. He did not B.`), "-라니/-다니" 횟수까지 확인. **문제 문장만 AI로 고치기**, 되돌리기 가능 | 고칠 때만 |
| 🔁 반복 끊기 | 최근 답변에서 3번 이상 나온 표현·같은 첫 문장을 찾아 다음 답변에서 피하게 함 (「🧹 반복 끊기」 방식, 이 채팅 맞춤). **AI로 버릇 찾기**로 몸짓·문장 구조 버릇도 찾아 채팅별로 저장 | 버릇 찾기 때만 |
| 📊 MVU | MVU가 돌아가면 `stat_data.캐해`(가면균열, 가치 기울기, 최근 갈등)를 추적하고 턴당 변화량을 제한. 추론의 "Output only the story"를 "본문 뒤 변수 블록"으로 고쳐 보내서 MVU 블록이 빠지지 않게 함 | 없음 |

## 설치

**방법 A — 주소로 설치 (권장)**
1. 실리태번 확장 패널 → **Install extension**
2. `https://github.com/sdafaff346/st-lemonaprom` 입력

**방법 B — 폴더 복사**
1. `SillyTavern-Lemona` 폴더를 `SillyTavern/data/<사용자명>/extensions/` 에 넣습니다 (기본: `data/default-user/extensions/`).
2. 새로고침

설치하면 확장 패널에 **🍋 레모나 도우미** 서랍이 생깁니다. 예전 **Character Insight** 확장을 쓰셨다면 꺼 주세요. 저장해 둔 캐해는 그대로 읽어옵니다.

> ⚠️ 확장은 브라우저에서 JavaScript를 실행합니다. 이 확장이 바깥으로 보내는 건 위 표의 "API 사용" 때 **내가 고른 API**로 가는 요청뿐입니다.

## 켜기 · 끄기

> 캐해만 빼고 쓰고 싶다면 서랍 🧠 캐릭터 해석 맨 위의 **캐해 기능 쓰기**를 끄세요. 금지어 검수, 반복 끊기, 토글 도우미는 계속 일해요.


서랍 맨 위 레몬 카드에 스위치가 두 개 있어요.

| 스위치 | 기본값 | 하는 일 |
|---|---|---|
| **레모나 도우미** (큰 스위치) | 켬 | 끄면 아예 쉬어요. 프롬프트에 아무것도 넣지 않고, 추론 줄도 안 붙이고, 답 검사·형광펜·배지·MVU 보정·토글 자동 적용이 전부 멈춰요. 이미 칠해 둔 형광펜과 배지도 지워요. |
| **레모나 프리셋에서만 켜기** | 켬 | 다른 프리셋으로 바꾸면 알아서 쉬고, 레모나로 돌아오면 다시 일해요. 끄면 다른 프리셋에서도 일반 모드로 일해요. |

- 🪄 메뉴의 **레모나 도우미 끄기 / 켜기**, 슬래시 커맨드 `/lemona off`, `/lemona on` 으로도 바꿀 수 있어요.
- 꺼져 있거나 쉬는 동안엔 🪄 메뉴에서 기능 항목이 숨겨지고, 서랍 머리에 `꺼짐` / `쉬는 중` 이 표시돼요.
- 저장해 둔 캐해, 토글 세트, 버릇 목록은 꺼도 그대로 남아 있어요.

## Gemini 4 Carbon을 쓴다면

Carbon은 설정이 맞지 않으면 아예 답을 주지 않으니 아래 세 가지를 꼭 맞춰 주세요.

| 설정 | 값 | 이유 |
|---|---|---|
| 레모나 토글 | **🔶 Carbon 호환 켜기, 🔷 Argon 호환 끄기** | Carbon 항목은 Argon "대신" 켜는 항목이에요. 둘 다 켜면 지시가 부딪혀요 |
| 빈도 페널티 · 존재 페널티 | **둘 다 0** | 0이 아니면 **400 오류**가 나요 |
| 추론 강도 (Reasoning Effort) | **low** | Carbon 호환 항목이 "짧게 생각하고 바로 쓰기"를 전제로 해요 |

확장이 이 세 가지를 확인해서, 맞지 않으면 서랍 맨 위 점검 칸에 알려 줍니다. (페널티는 경고, 추론 강도는 안내)

## 다인봇 · 시뮬봇 · RPG봇

카드 분석이 먼저 카드 종류를 정하고, 종류에 맞게 다른 내용을 만듭니다. 편집 창 맨 위 **카드 종류** 칩으로 직접 바꿀 수 있고, 바꾼 뒤 **다시 분석**하면 그 종류로 분석해요.

| 종류 | 이런 카드 | 만드는 것 |
|---|---|---|
| 단일 캐릭터 | 캐릭터 한 명 | 겉과 속, 가치 쌍, 사람에 따라 (지금까지와 같음) |
| 다인봇 | 정해진 여러 인물이 같이 나옴 (남매, 파티, 하숙집…) | **등장인물** 최대 8명: 어떤 사람·보여주는 모습·속·말투/버릇·자기 가치 쌍 |
| 시뮬봇 | {{char}}가 세계나 내레이터, 사람이 들고 남 | **세계**(사람을 대하는 방식, 이름 없는 사람 쓰는 법), **세계의 긴장**(가치·세력 쌍), **주요 인물** |
| RPG봇 | 퀘스트·스탯·전투·시스템 창 | 시뮬봇과 같음 + NPC는 자기 이익대로 돕고 거절하고 흥정하며, {{user}}가 한 일을 기억 |

- **장면에 나온 인물만 자세히**(기본 켜짐): 최근 메시지 4개(바꿀 수 있음)에 이름이나 다른 이름이 나온 인물만 넣고, 나머지는 이름만 적어 둡니다. 3명 이하면 늘 다 넣고, 다인봇에서 아무도 안 나오면 다 넣어요. 한 글자 이름은 단어 첫머리일 때만 인식해요.
- **채팅 반영 분석**은 종류를 그대로 두고 인물들을 지금 모습으로 고칩니다. 바뀐 인물에는 "이 채팅에서 달라진 점"을 적고, 채팅에서 자주 나오게 된 인물은 새로 추가해요 (시뮬·RPG에서 특히 유용).
- 다인봇은 레모나 「👥 선택: 다인봇 시장통 방지」를 추천에 넣어요.
- 🔍 추론 확인 줄은 "이 장면의 누가 무엇을 원하는지, 각자 목소리를 구별"로 바뀌어요.
- MVU 가면 균열·기울기는 한 사람을 추적하는 값이라 단일 캐릭터에서만 씁니다.
- 실리태번 **그룹 채팅**(캐릭터 카드 여러 장)은 아직 지원하지 않아요. 카드 한 장이 여러 인물을 연기하는 경우가 다인봇입니다.

## 긴 채팅: 카드 버전과 채팅 버전

카드만 보고 만든 캐해를 이미 많이 진행한 채팅에 넣으면, 채팅에서 달라진 캐릭터를 카드 상태로 되돌리려 해서 오히려 평면적이 될 수 있어요. 그래서 캐해가 두 가지가 됐습니다.

| | 카드 버전 | 이 채팅 버전 |
|---|---|---|
| 만드는 법 | 🧠 **카드 분석** | 🧠 **채팅 반영 분석** |
| 읽는 것 | 카드 + 로어북 | 카드 요약 + 로어북 + 지금까지의 캐해 + **최근 채팅** |
| 저장 | 캐릭터 카드 (모든 채팅) | 이 채팅에만 |
| 우선순위 | 채팅 버전이 없을 때 | 있으면 항상 이쪽 |

- **채팅 반영 분석**은 캐릭터가 지금 어떤 모습인지로 캐해를 다시 씁니다. 바뀐 것만 바꾸고 나머지는 그대로 두며, 예전 모습은 밑에 깔린 채로 남겨요. "이 채팅에서 달라진 점"(최대 3줄, 무엇이 계기였는지 포함)도 따로 적어서 그건 지키게 합니다.
- **긴 채팅에선 카드 버전 옅게**(기본 켜짐): 채팅 버전이 없고 AI 답변이 40개(바꿀 수 있음)를 넘으면, 카드 버전은 깊은 동기(진짜 욕구·두려움·착각, 가치 쌍의 이름과 기울기)만 넣고 겉모습·행동·사람별 모습은 빼요. 말투와 행동은 채팅을 따릅니다.
- 어느 버전이든 "지금까지의 채팅이 이 메모보다 우선한다, 달라진 모습을 되돌리지 말라"는 줄이 들어가고, 「🔍 추론」 확인 줄도 같은 뜻으로 바뀌었어요.
- 편집 창 위쪽에 지금 어느 버전인지 떠요. 버튼으로 카드 버전 ↔ 채팅 버전을 오가고, 채팅 버전만 지워서 카드로 돌아갈 수 있어요.
- 슬래시 커맨드: `/lemona reread` = 채팅 반영 분석.

## 로어북 분석

캐해 분석 때 카드와 함께 로어북도 읽습니다 (서랍 🧠 캐릭터 해석 → 로어북).
- 읽는 책: 캐릭터에 연결된 로어북(기본 + 추가 로어북), 채팅 로어북. 카드에 내장된 로어북이 아직 가져오기 전이면 그것도 읽어요. "전역 로어북도 넣기"를 켜면 전역·페르소나 로어북까지.
- 꺼진 항목, 변수·상태창·HTML 같은 기술용 항목(`[InitVar]`, `{{setvar}}`, `<%`, 상태창·美化 제목 등)은 뺍니다.
- 상시 켜진 🔵 항목과 캐릭터 이름이 나오는 항목부터 넣고, "로어북 최대 글자 수"(기본 12000자)를 넘으면 나머지는 뺍니다. 항목 하나는 1500자까지.
- 로어북은 동기와 원인을 잡는 근거로만 쓰고, 세계관 설명을 캐해에 옮겨 적지 않아요. 카드와 다르면 카드가 우선입니다.
- 분석 결과에 **사람에 따라** 칸이 생겼어요. 카드·로어북에 나오는 인물 앞에서 겉이나 속이 다르게 드러나는 방식을 최대 3명까지 적고, 그 사람이 장면에 있을 때만 쓰게 합니다. {{user}}는 넣지 않아요.

## 모델 따라 🔷 / 🔶 자동 전환

연결된 모델 이름을 보고 토글을 맞춥니다 (서랍 🎛️ 토글 도우미에서 끌 수 있어요).

| 모델 | 🔷 Argon 호환 | 🔶 Carbon 호환 |
|---|---|---|
| 이름에 `argon` | 켬 | 끔 |
| 이름에 `carbon` | 끔 | 켬 |
| 그 밖 (3.8 Flash, Claude…) | 끔 | 끔 ("다른 모델이면 둘 다 끄기"를 끄면 그대로) |

- 모델·소스·연결 프로필·프리셋이 바뀐 뒤 잠깐 기다렸다가 한 번 맞추고, 보내기 직전에 한 번 더 확인합니다.
- 모델이 그대로면 손으로 바꾼 상태를 존중해요. 모델이 바뀌면 다시 맞춥니다.
- 🔶가 없는 프리셋(v7.2.1)에서 Carbon을 쓰면 아무것도 바꾸지 않아요.

**캐릭터별 토글 세트와 실리태번 연결 프로필** — 연결 프로필을 고르면 실리태번이 프리셋 파일을 다시 불러와서 토글이 파일 상태로 돌아갑니다. 예전에는 이때 캐릭터 세트가 풀리고, 반대로 채팅을 열 때 세트에 저장된 🔷/🔶이 모델과 엇갈리게 켜졌어요. 이제는 이렇게 동작합니다.
- 캐릭터 세트에는 🔷/🔶을 저장하지 않아요. 예전에 저장한 세트에 들어 있어도 무시합니다.
- 프리셋을 다시 불러오면 캐릭터 세트를 다시 적용하고, 그다음 🔷/🔶을 모델에 맞춥니다.

## 보조 API

캐해 분석·금지어 고치기·버릇 찾기는 **보조 API**를 씁니다.
- 기본값은 "본 채팅과 같은 API"입니다.
- 실리태번 **연결 프로필(Connection Profile)** 을 만들어 두면 서랍의 "🔌 보조 API"에서 고를 수 있어요. 본 채팅은 비싼 모델, 보조 작업은 싼 모델로 나눌 수 있습니다.
- Vertex AI 연결 프로필은 본 채팅의 인증 방식(Express)·프로젝트 ID·리전을 이어받아 보냅니다. 프로필 요청이 실패하면 본 채팅 API로 한 번 다시 보내요.
- 응답이 JSON 중간에서 잘리면 "응답 길이"를 늘리세요.
- 분석 결과 언어는 기본으로 「🌐 언어 택1」에 켜 둔 언어를 따라갑니다. 영챗이면 캐해도 영어로 나와요. 설정에서 한국어·영어로 고정할 수도 있습니다.

## 쓰는 법

**처음 한 번 (캐릭터마다)**
1. 1:1 채팅을 엽니다.
2. 🪄 메뉴 → **캐해 분석** → 편집 창에서 확인·수정 → **저장**.
3. 편집 창의 "③ 레모나 토글 추천"에서 **추천대로 토글 바꾸기** (선택).
4. 🪄 메뉴 → **레모나 토글** → 마음에 들게 맞춘 뒤 **지금 토글을 이 캐릭터용으로 저장**. 다음부터 이 캐릭터 채팅을 열면 자동으로 바뀝니다.

**채팅 중**
- 답변 아래 `🚫 금지어 2 · 구조 1` 배지 → 눌러서 목록 확인 → **AI로 고치기** / **고치기 전으로**.
- 서랍의 "🔁 반복 끊기"에 지금 피하게 하는 표현이 보입니다. 답변이 좀 쌓이면 **AI로 버릇 찾기**.

**슬래시 커맨드** `/lemona analyze | edit | toggles | check [번호] | fix [번호] | habits | show | health | on | off`

## 프롬프트에 들어가는 위치 (레모나일 때)

```
… 👤 현실적·캐해·로맨스 (</realism>)
<character_insight>          ← 캐해 (확장)
… 금지단어, 사칭, 리롤 변주 …
<thinkingProcess> … 5. Stop …
{{getvar::chk_*}} 체크 줄들 (프리셋)
- Insight: …                 ← 캐해 확인 줄 (확장)
Narration is in …
[Note for this reply only …] ← 반복 끊기 (깊이 1)

```
프리셋 파일은 바꾸지 않습니다. 보낼 때만 끼워 넣어요.

## 다른 확장과 함께 쓸 때

아래 확장들과 코드를 맞춰 봤습니다. **모두 같이 켜도 됩니다.**

| 확장 | 결과 |
|---|---|
| 코끼리를 생각하지마 | 같이 켜도 됨. 단 그쪽 "금지어·반복 표현"과 이 확장의 "반복 끊기"는 **하는 일이 겹침** (아래 참고) |
| 책먹는여우 | 겹치는 것 없음 |
| blue-lemonade | 겹치는 것 없음 (테마·UI) |
| Interpres 커스텀모드 | 같이 켜도 됨. 번역된 메시지에는 형광펜을 넣지 않고 배지만 띄움 |
| 백그라운드 답장 (ST-Background-Reply) | 같이 켜도 됨. 백그라운드 답변에도 캐해가 들어가고 금지어 검사도 돌아감 |
| 🪄전개지시M (Direction-Manager-DB) | 같이 켜도 됨. 전개 지시와 캐해가 각자 자리에 들어감 |
| Direction-Manager-Lite | 같이 켜도 됨. 위와 같음 |
| Mermaid (Extension-Mermaid) | 같이 켜도 됨. ` ```mermaid ` 코드 블록 안은 금지어 검사·형광펜·반복 감지가 건드리지 않음 |
| 과실지심(果实之心) 같은 모델 연동 스크립트 | 레모나 프리셋에서는 해당 없음. 다른 프리셋을 쓸 땐 "레모나에서만 켜기"가 켜져 있으면 이 확장은 쉬어서 겹치지 않음 |

**코끼리를 생각하지마와 겹치는 기능** — 둘 다 최근 답변에서 반복되는 표현을 찾지만 처리 방식이 달라요. 코끼리는 기억·최근 대화에서 그 단어를 **빼고** 보내고, 이 확장은 다음 답변에서 **피하라고** 지시합니다. 둘 다 켜면 같은 취지의 지시가 두 번 들어가니 한쪽만 쓰는 걸 권해요. 코끼리가 깔려 있으면 서랍 점검 칸에 안내가 뜹니다.

**백그라운드 답장과 함께** — 백그라운드 답장은 프롬프트가 조립된 **뒤에** 가져가기 때문에, 백그라운드로 받는 답변에도 캐해·MVU 규칙·반복 끊기가 그대로 들어갑니다. 금지어 "AI로 고치기"는 다음 경우 적용하지 않고 알려 줍니다: 고치는 동안 다른 채팅으로 옮겼을 때, 그 메시지가 바뀌었을 때, 아직 생성 중일 때.

**전개지시 확장과 함께** — 두 Direction Manager 모두 대화 끝에서부터 센 깊이로 지시를 넣고, 이 확장은 앞쪽(`</realism>` 뒤)과 추론 블록 안에 넣습니다. 끼워 넣는 자리가 달라서 어느 쪽이 먼저 돌든 결과가 같습니다. 깊이 1이면 전개 지시는 「🔍 추론」 바로 앞에 들어가요.

> 참고: Direction-Manager-DB와 Direction-Manager-Lite는 **서로** 같은 `{{direction}}` 매크로와 화면 이름을 써서, 둘 중 하나만 켜야 합니다. (이 확장과는 무관)

## 한계

- 그룹 채팅에서는 캐해·반복 끊기가 꺼집니다 (금지어 검사는 됨).
- 토글 변경은 "현재 설정"에 저장됩니다. 프리셋 파일에 남기려면 평소처럼 프리셋을 저장하세요.
- 금지어 검사는 단어 앞부분으로 판단해서 드물게 엉뚱한 단어에 걸릴 수 있어요. 소유 표현(내 거 등)은 사물 얘기일 수 있어 표시만 하고 고치지 않습니다.
- 금지단어 A·B·C 항목은 한국어 단어라 영어 서술에서는 걸리지 않습니다. 영어에서는 소유 표현(`mine`)과 교정 대비 구조를 잡습니다.
- 반복 감지는 글자 그대로 같은 표현만 잡습니다. 비슷한 뜻의 다른 표현은 "AI로 버릇 찾기"를 쓰세요.
