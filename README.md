# 🍋 레모나 도우미 (Lemona Companion)

**레모나 프리셋 전용** SillyTavern 확장입니다. **v6.9.1 / v7.2.1 둘 다 확인**했습니다. 레모나의 구조(`</realism>`, `<thinkingProcess>`, 택1 토글, 「🚫 금지단어」)를 알아보고 그 안에 맞춰 끼워 넣습니다. 다른 프리셋에서는 일반 모드로 돌아갑니다.

| 기능 | 하는 일 | API 사용 |
|---|---|---|
| 🧠 캐릭터 해석 | 카드를 분석해 **겉과 속**(보여주는 모습·진짜 욕구·두려움·착각)과 **충돌하는 가치 쌍**을 만들고, 「👤 현실적·캐해·로맨스」 바로 뒤에 넣음. 「🔍 추론」 체크리스트에 캐해 확인 줄도 추가 | 분석할 때 1번 |
| 🎛️ 토글 도우미 | 택1 그룹을 드롭다운으로 바꾸기, 구성 점검(택1 중복, 끄지마요 항목, 메신저+상태창 충돌 등), **캐릭터별 토글 세트** 저장·자동 적용, 분석 결과로 **토글 추천** (1차/2차봇, 혐성/젠틀, 로코, 앵스트, 분위기…) | 없음 (추천은 분석에 포함) |
| 🚫 금지어 검수 | 지금 프리셋의 「🚫 금지단어」를 그대로 읽어 답변마다 검사 → 본문 형광펜 + 배지. 파생형(서늘한→서늘하게), 제한어 1회·연속 금지, 교정 대비 구조(`A가 아니라 B` · `not A but B` · `He did not A. He did not B.`), "-라니/-다니" 횟수까지 확인. **문제 문장만 AI로 고치기**, 되돌리기 가능 | 고칠 때만 |
| 🔁 반복 끊기 | 최근 답변에서 3번 이상 나온 표현·같은 첫 문장을 찾아 다음 답변에서 피하게 함 (「🧹 반복 끊기」 방식, 이 채팅 맞춤). **AI로 버릇 찾기**로 몸짓·문장 구조 버릇도 찾아 채팅별로 저장 | 버릇 찾기 때만 |
| 📊 MVU | MVU가 돌아가면 `stat_data.캐해`(가면균열, 가치 기울기, 최근 갈등)를 추적하고 턴당 변화량을 제한. 추론의 "Output only the story"를 "본문 뒤 변수 블록"으로 고쳐 보내서 MVU 블록이 빠지지 않게 함 | 없음 |

## 설치

1. `SillyTavern-Lemona` 폴더를 `SillyTavern/data/<사용자명>/extensions/` 에 넣습니다 (기본: `data/default-user/extensions/`).
2. 새로고침 → 확장 패널에 **🍋 레모나 도우미** 서랍이 생깁니다.
3. 예전 **Character Insight** 확장은 꺼 주세요. 저장해 둔 캐해는 그대로 읽어옵니다.

> ⚠️ 확장은 브라우저에서 JavaScript를 실행합니다. 이 확장이 바깥으로 보내는 건 위 표의 "API 사용" 때 **내가 고른 API**로 가는 요청뿐입니다.

## 보조 API

캐해 분석·금지어 고치기·버릇 찾기는 **보조 API**를 씁니다.
- 기본값은 "본 채팅과 같은 API"입니다.
- 실리태번 **연결 프로필(Connection Profile)** 을 만들어 두면 서랍의 "🔌 보조 API"에서 고를 수 있어요. 본 채팅은 비싼 모델, 보조 작업은 싼 모델로 나눌 수 있습니다.
- 응답이 JSON 중간에서 잘리면 "응답 길이"를 늘리세요.

## 쓰는 법

**처음 한 번 (캐릭터마다)**
1. 1:1 채팅을 엽니다.
2. 🪄 메뉴 → **캐해 분석** → 편집 창에서 확인·수정 → **저장**.
3. 편집 창의 "③ 레모나 토글 추천"에서 **추천대로 토글 바꾸기** (선택).
4. 🪄 메뉴 → **레모나 토글** → 마음에 들게 맞춘 뒤 **지금 토글을 이 캐릭터용으로 저장**. 다음부터 이 캐릭터 채팅을 열면 자동으로 바뀝니다.

**채팅 중**
- 답변 아래 `🚫 금지어 2 · 구조 1` 배지 → 눌러서 목록 확인 → **AI로 고치기** / **고치기 전으로**.
- 서랍의 "🔁 반복 끊기"에 지금 피하게 하는 표현이 보입니다. 답변이 좀 쌓이면 **AI로 버릇 찾기**.

**슬래시 커맨드** `/lemona analyze | edit | toggles | check [번호] | fix [번호] | habits | show | health`

## 프롬프트에 들어가는 위치 (레모나일 때)

```
… 👤 현실적·캐해·로맨스 (</realism>)
<character_insight>          ← 캐해 (확장)
… 금지단어, 사칭, 리롤 변주 …
<thinkingProcess> … 5. Stop …
- Canon: … (프리셋)
- Insight: …                 ← 캐해 확인 줄 (확장)
Narration is in Korean …
[Note for this reply only …] ← 반복 끊기 (깊이 1)
<character_insight_variable_rules> ← MVU 규칙 (깊이 0, MVU일 때)
```
프리셋 파일은 바꾸지 않습니다. 보낼 때만 끼워 넣어요.

## v1.1.0에서 바뀐 것 (v6.9.1 반영)

- **🔶 Carbon 호환 항목을 알아봅니다.** v6.9.1에 새로 생긴 항목이에요. Argon과 Carbon을 같이 켜면 경고가 뜨고(Carbon은 Argon "대신" 켜는 항목), 지금 모델과 안 맞으면 알려 줍니다. 모델 이름에 argon/carbon이 있는데 해당 호환이 꺼져 있으면 켜라고 권해요.
- **분석 결과 언어 기본값이 "프리셋 서술 언어에 맞춤"으로 바뀌었습니다.** 「🌐 언어 택1」에서 켜 둔 항목을 읽어서 그 언어로 분석해요. 영챗(English US)이면 캐해도 영어로 나옵니다. 언어 택1이 꺼져 있거나 두 개 켜져 있으면 카드 언어를 따라가요. 기존처럼 고정하고 싶으면 설정에서 한국어/영어를 고르면 됩니다.
- **영어 교정 대비 구조를 잡습니다.** 금지 목록이 지목한 `He did not A. He did not B. He C.` 형태와 `not A but B`를 검사해요. 같은 주어로 된 부정문이 2문장 이상 이어질 때만 잡아서, 평범한 부정문 하나는 넘어갑니다.

v6.9.1과 v7.2.1은 금지단어 목록이 완전히 같고, 확장이 끼워 넣는 지점(`</realism>`, `<thinkingProcess>`, `Output only the story.`)도 둘 다 그대로 있어서 한 버전만 쓰셔도 되고 오가며 쓰셔도 됩니다.

## 다른 확장과 함께 쓸 때

같이 쓴다고 알려 주신 확장들과 맞춰 봤습니다. **네 개 모두 같이 켜도 됩니다.**

| 확장 | 결과 |
|---|---|
| 코끼리를 생각하지마 | 같이 켜도 됨. 단 그쪽 "금지어·반복 표현"과 이 확장의 "반복 끊기"는 **하는 일이 겹침** |
| 책먹는여우 | 겹치는 것 없음 |

| Interpres 커스텀모드 | 같이 켜도 됨. 번역된 메시지에는 형광펜을 넣지 않고 배지만 띄움 |
| 백그라운드 답장 (ST-Background-Reply) | 같이 켜도 됨. 백그라운드 답변에도 캐해가 들어가고 금지어 검사도 돌아감 |

### 백그라운드 답장과 함께 (v1.1.1)

백그라운드 답장은 프롬프트가 조립된 **뒤에** 가져가기 때문에, 백그라운드로 받는 답변에도 캐해·MVU 규칙·반복 끊기가 그대로 들어갑니다. 받아 온 답변에도 금지어 배지가 붙습니다.

**v1.1.1에서 고친 것** — 채팅을 떠난 사이에 답장이 도착하는 게 이 확장의 사용 방식이라, 금지어 "AI로 고치기"에 안전장치를 넣었습니다.
- 고치는 동안 **다른 채팅으로 옮기면** 적용하지 않고 알려 줍니다. (전에는 엉뚱한 채팅에 저장될 수 있었어요.)
- 고치는 동안 **그 메시지가 바뀌면** 적용하지 않습니다.
- **아직 생성 중인 답변**은 건드리지 않습니다. 검사와 배지는 그대로 뜨고, 끝난 뒤에 고칠 수 있어요.

**v1.0.1에서 고친 것**
- 코끼리를 생각하지마가 쓰는 `#lm_settings` / `.lm-*` 이름을 이 확장이 똑같이 쓰고 있었습니다. 전부 `lmc_` / `.lmc-` 로 바꿨습니다. (그대로 두면 서로의 설정 패널과 팝업 모양이 깨졌습니다.)
- Interpres처럼 메시지 화면 표시를 바꾸는 확장이 있으면, 그 메시지에는 형광펜을 넣지 않습니다(번역문에 엉뚱한 단어가 표시되는 걸 막기 위해). 배지는 그대로 뜹니다.
- 금지어 고치기는 원문을 바꾸고, 다른 확장이 만든 번역문은 건드리지 않습니다. 대신 "그 확장을 다시 실행해 주세요"라고 알려 줍니다.
- 설정 패널 점검 칸에 겹치는 확장이 있으면 안내가 뜹니다.

**겹치는 기능 (한쪽만 쓰기 권장)**

코끼리의 "금지어·반복 표현"과 이 확장의 "반복 끊기"는 둘 다 최근 답변에서 반복되는 표현을 찾습니다. 다만 처리 방식이 달라요.
- 코끼리: 기억·최근 대화에서 그 단어를 **빼고** 보냅니다.
- 레모나 도우미: 다음 답변에서 **피하라고** 지시합니다.

둘 다 켜면 같은 취지의 지시가 두 번 들어갑니다. 한쪽을 끄시는 게 좋아요.
